# Fixture verification

Task 1.1, run 2026-10-27 on macOS arm64 with FFmpeg 8.1.

Commands:

```sh
bun scripts/media-playback-fixtures.ts
bun scripts/media-playback-fixtures.ts data/media-playback-fixtures-repeat
```

Both runs passed all assertions. All six SHA-256 hashes matched across runs.
`fixture-manifest.json` records hashes, exact subprocess arguments, codec metadata,
frame IDs and presentation timestamps. Raw input is generated by the script.
Codec-version changes can change encoded hashes. Compare hashes with the recorded
FFmpeg version.

Each video has a visible eight-bit frame ID across its top row. The leftmost cell
is the least significant bit. Every decoded frame retained its expected ID.
The 160×96 fixtures include 24-frame CFR H.264/AAC, 16-frame VFR silent H.264,
silent H.264 starting at 5 seconds, and silent VP9 WebM. VFR presentation
intervals differ. Silent fixtures contain no audio track.

The two mono PCM files contain two seconds at 44100 and 48000 Hz. Samples zero
and `sampleRate` have amplitude 0.5. Every other sample is zero. Decoding to
signed 16-bit PCM produced exactly 16384 at each impulse and zero elsewhere.

Generated media stays under ignored `data/`. This check proves fixture decoding
with FFmpeg. Browser codec acceptance remains task 2.3. These small fixtures do
not replace the long performance and synchronization fixtures in group 7.
